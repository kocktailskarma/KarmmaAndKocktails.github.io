Privacy policy

Last updated: 30 October 2026

restaurant-management is a private, internal tool for the owner and manager of a small group of restaurants. It is used only with the owner's own Google account. It has no other users.

What the tool accesses

With the owner's permission it uses one Google permission, drive.file. That permission lets the tool see and change only the files and folders the tool itself created in the owner's Google Drive (for example a folder called "Restaurant Dashboard" holding compressed database backups, receipt photos and report spreadsheets). The tool cannot see any other file in the account, and it does not access email, contacts, calendar or photos.

How the information is used

The files hold the restaurants' own business records: daily sales totals, expense records and receipt images. They are used only to keep those records, to make backups of them and to show them to the owner and manager in a report.

Sharing

The tool does not sell, rent or share information from Google with anyone. Information from Google is not used for advertising and is not read by people other than the owner and manager.

Storage and security

The permission token is kept as an encrypted secret in the owner's private GitHub repository and on the owner's own computer. It is never published.

Google API Services User Data Policy

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

The owner can withdraw the permission at any time at myaccount.google.com/permissions and can delete the tool's files and folders from Google Drive.
